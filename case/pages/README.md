# case/pages/ — ham yarışma metinleri

**Aşama:** 1, her şeyden önce. Dosya adı: `<kaynak>-<HHMM>.md`.

Overview, Data, Evaluation, Rules **ayrı dosyalardır**. Gelen metin **özetlenmeden**
olduğu gibi yazılır — özet `case/CASE.md`'de yapılır.

**Kim yazar:** insan yapıştırır (Kaggle sayfaları genelde login arkasındadır, WebFetch
30 saniyede gelmezse bırakılır), ajan kaydeder.

**Neden ham:** `CASE.md` ile ham metin çeliştiğinde **hakem burasıdır**. Gece yarısı
"metrik gerçekten bu muydu" sorusunun tek güvenilir cevabı bu klasördedir.

**Ne zaman sabitlenir:** yazılan dosya değiştirilmez; yeni sürüm yeni dosyadır.
